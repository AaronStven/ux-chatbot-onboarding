# 🧠 UX Study: Chatbot Onboarding

A mixed-methods HCI research project evaluating three onboarding flows for a university campus chatbot.

## 📖 Overview
Campus chatbots often suffer from poor adoption due to confusing initial interactions. I designed three onboarding prototypes and conducted a formal usability study to determine which flow minimizes cognitive load and maximizes task completion.

## 🛠 Methods & Tools
- **Study Design:** Within-Subjects (12 participants).
- **Data Collection:** Think-aloud protocol, task metrics, SUS (System Usability Scale), and NASA-TLX.
- **Analysis:** Quantitative data analyzed via Python (pandas); Qualitative data analyzed via Thematic Analysis.

## 📂 Repository Structure
- [`docs/study-protocol.md`](docs/study-protocol.md) - How the study was designed and executed.
- [`docs/findings-report.md`](docs/findings-report.md) - The final report with quantitative data and design recommendations.
- [`data/usability_metrics.csv`](data/usability_metrics.csv) - Raw anonymized data from the 12 participants.

## 💡 Key Results
- **Prototype B (Buttons/Carousels)** scored a **SUS of 83.5 (Grade A)** compared to Prototype A's 65.0.
- Task completion time was **48% faster** with buttons compared to free-text conversation.
- **Recommendation:** A hybrid flow using initial buttons to guide the user, transitioning to free text as the conversation progresses.
